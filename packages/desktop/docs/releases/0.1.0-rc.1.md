## 安装与卸载

- Windows：运行对应架构的 `.exe`，按向导安装；从系统“已安装的应用”卸载
- macOS：挂载 `.dmg`，将 Pi Orbit 拷贝到“应用程序”；退出后移至废纸篓卸载。此包没有 Developer ID 签名或 Apple 公证，系统可能拒绝打开
- Linux：给 `.AppImage` 添加执行权限后运行；需要桌面运行库及系统可用的 FUSE 支持。删除 AppImage 即可移除程序
- 卸载应用不保证删除个人设置和会话。首次试用前请备份已有数据，不要把测试结果当作数据恢复保障

## 已知限制

冒烟检查使用本地模拟模型服务和一次性配置，覆盖原生终端、聊天、设置保存、关闭重启与中断任务恢复；没有调用真实付费模型。真实 OAuth、系统钥匙串权限、所有模型提供商、复杂工具执行、Git 冲突处理、突然断电及全部交互界面尚未完整验收。

扩展并非全部支持桌面 UI。自定义 TUI 控件、终端主题、覆盖层及部分编辑器接口会显示 `unsupported_desktop_ui`，仍需逐例验收。本版仅覆盖上列明确构建的架构，不代表其他架构已获验证。

此 Release 只发布桌面安装包，不发布 npm 包，不更新 R2 或 Pi 官网版本标记，也不启用自动更新。
